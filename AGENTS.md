# AGENTS.md

This is the runtime bootstrap file for agent task runs.

Before doing any work:

1. Read `TASK_BRIEFING.md`.
2. Read `AGENTS_INSCTRUCTIONS.md` in full.
3. Treat `TASK_BRIEFING.md` as the run-specific assignment and `AGENTS_INSCTRUCTIONS.md`
   as the durable operating policy.
4. Follow the role policy included in the context pack, plus the system rules in
   `AGENTS_INSCTRUCTIONS.md`.
5. Use MCP tools for system interaction, including `message_send` for operator replies,
   and finish with a handoff note or task update.

If either `TASK_BRIEFING.md` or `AGENTS_INSCTRUCTIONS.md` is missing, stop and report
that the runtime bootstrap is incomplete.
